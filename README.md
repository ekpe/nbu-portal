# NBU Portal

Nigerian British University Portal System built with Next.js, TypeScript, Tailwind CSS, PostgreSQL, Prisma, GitHub, and Vercel.

## Stack
- Next.js
- TypeScript
- Tailwind CSS
- PostgreSQL
- Prisma
- Vercel

## Environments
- local
- preview
- production

## Setup
1. Copy `.env.example` to `.env`
2. Set `DATABASE_URL`
3. Run `npm install`
4. Run `npx prisma generate`
5. Run `npx prisma migrate dev --name init`
6. Run `npm run dev`
